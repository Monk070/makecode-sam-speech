# SAM Text-to-Speech for MakeCode Arcade

A high-quality speech synthesizer based on the classic SAM (Software Automatic Mouth) algorithm.

## Features
- Authentic SAM formant synthesis
- 6 voice presets (SAM, Elf, Little Robot, etc.)
- 300+ word pronunciation dictionary
- Smooth phoneme interpolation
- Adjustable pitch, speed, throat, and mouth parameters

## Usage
Add this extension to your MakeCode Arcade project and use blocks like:
- `speak "hello"`
- `set voice to SAM (default)`
- `set voice speed pitch throat mouth`
